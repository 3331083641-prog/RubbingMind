# 墨韵智考 · 统一石碑三维模型规范

本轮六面最终工程以 `steleDimensions.ts` 为尺寸入口，使用 Blender 5.1.2 制作闭合雕刻网格并导出 GLB。原三视图程序化方案已由统一 GLB 替代，首页、全屏与旧 Hero 兼容入口使用同一模型。

| 参数 | 成品规格 |
| --- | --- |
| 总高 / 碑宽 / 厚度 | 3.30m / 1.28m / 0.24m |
| 底座宽 / 深 / 高 | 1.85m / 0.72m / 0.55m |
| 碑身 / 插入段 / 拱高 | 2.15m / 0.04m / 0.64m |
| 主体几何 | 七个闭合石体岛，319,024 三角面 |
| 运行材质 | 一个非金属 PBR 材质；颜色、法线、粗糙度、AO 完整 |
| UV | UV0 图集；UV1 独立 Cycles AO 烘焙 |
| 坐标 | glTF Y 向上，+Z 为正面，原点为基底中心 |

双龙与宝珠在闭合拱体皮层上形成真实几何起伏。须弥座卷草和莲瓣在支撑石面雕刻，禁止独立白色片状构件。字面在碑体内凹表面，使用清楚标记的参考概念铭文；细小阴刻由法线补充，扫描和热点限定在正面碑文字域。

参考图来源为用户提供的六张生成图，不是测绘资料或历史碑文原件。背面没有铭文；左右石材分别登记；俯视采用参考的斜俯视，仰视无地面遮挡。
