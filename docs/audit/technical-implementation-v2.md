## 预先确定的实验设计

以文物ID作为独立统计与划分单位；开发/测试文物分离，覆盖七朝代；不按结果筛选样本。统一预注册裁切规则和两档退化强度，记录来源、许可、输入/输出SHA和随机种子。各方法共享输入并随机运行顺序。置信区间按文物聚类重采样，不能把同碑多个退化当独立文物。相对清晰拓本仅为受控实验参考，不是历史真值。OCR没有可靠人工标签时拒绝报告准确率。
