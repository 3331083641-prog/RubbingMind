## 二、 三维石碑几何结构与部件拓扑层次

为彻底解决旧模型“正面空心展柜、侧背纯灰无纹、顶部悬空球体、底座规则齿轮片”等缺陷，新几何模型采用全实心封闭网格（Watertight Solid Meshes），由 `SteleRoot` 统一组织：

```text
SteleRoot (统一几何原点：底座底面中心，+Y为向上，+Z为正前方)
│
├── SteleBody (实心碑身主体)
│   ├── FrontInscriptionFace   # 正面内凹 0.015m 碑文雕刻面板 (对齐 UV0，挂载拓片漫反射)
│   ├── OuterStoneFrame        # 碑身四周微倒角石材边框及回纹浅浮雕
│   ├── BackStoneFace          # 背面连续实心石材表面 (对齐 back 纹理)
│   └── SideStoneFaces         # 左/右侧面厚度壁 (对齐 side 纹理与自然斜向裂纹)
│
├── SteleCrown (半圆拱双龙碑首)
│   ├── CrownArchSolid         # 圆拱形主体石块 (厚度与碑身严格一致 0.38m)
│   ├── TwinDragonRelief       # 双龙盘绕立体浮雕 (左右对称呼应，龙首、角、龙身鳞片)
│   └── CentralFlamePearl      # 中央浮雕宝珠 (非悬空球体，与龙身云气自然融接为一体浮雕)
│
└── Pedestal (多层雕花复合须弥座)
    ├── LotusTier              # 仰覆莲瓣装饰承台 (具有弧度厚度与倒角雕刻，严禁机械重复白片)
    ├── TransitionSlab         # 中层倒角承托石板
    ├── ScrollReliefTier       # 如意卷云回纹浮雕腰带 (四面连续闭合)
    └── FoundationPlinth       # 底层宽展平实承重石台 (带底面榫卯槽与四角垫石)
```

## 三、 标准物理尺寸与比例规范（基于唐宋官式碑碣营造法式）

- **总高度**：`3.85 m`（包含底座至碑顶）
- **碑身净高**：`2.35 m`
- **碑身宽度**：`1.15 m`
- **碑身厚度**：`0.36 m`（厚宽比约 `1:3.2`，严格杜绝过厚或片状过薄）
- **碑首拱高**：`0.65 m`，曲率半径 `R = 0.575 m`
- **碑文内凹嵌槽**：宽度 `0.92 m`，高度 `1.90 m`，深度 `-0.015 m`
- **底座总高**：`0.85 m`
  - 莲瓣承台（上层）：高度 `0.22 m`，宽度 `1.30 m`，厚度 `0.58 m`
  - 卷云腰线（中层）：高度 `0.30 m`，宽度 `1.46 m`，厚度 `0.72 m`
  - 承重石台（底层）：高度 `0.33 m`，宽度 `1.62 m`，厚度 `0.90 m`

## 四、 PBR 物理材质与纹理管线

所有构件统一采用非金属粗糙古代青石岩（Weathered Dark Basalt / Limestone）材质体系：

| 贴图通道 | 贴图格式 | 色彩空间 | 物理属性参数建议 |
| :--- | :---: | :---: | :--- |
| **Base Color (Albedo)** | PNG 2048×2048 | sRGB | 灰黑色（RGB 24~48，带土褐矿物斑驳颗粒，严禁纯黑 #000000） |
| **Normal Map (法线)** | PNG 2048×2048 | Linear (Non-Color) | 包含石材结晶微凹凸、断裂深沟槽与双龙/莲瓣浮雕法线 |

| **Metallic (金属度)** | 浮点常数 | Linear | 严格置为 `0.0`（纯非金属天然石质） |
| **Ambient Occlusion (AO)**| PNG 2048×2048 | Linear | 烘焙阴阳角微环境光遮蔽（浮雕深槽强化立体阴影） |

## 六、 激光扫描与微痕修复渲染联动

1. **激光扫描面 (Laser Scan Plane)**：
   - 限制在 `FrontInscriptionFace` 的内凹局部平面区域 $[X: -0.46 \sim 0.46, Y: 0.85 \sim 2.75]$；
   - 采用局部着色器计算，不穿透背面与侧面；
   - 支持沿 $Y$ 轴上下往复平滑扫掠，扫描带具备半透明黄金（`#D4AF37`）高斯光晕。
2. **修复进度双图材质融合**：
   - 采用 UV0 纹理插值，在当前碑拓的原始风化图（`damaged`）与微痕修复图（`restored`）之间根据 `restorationProgress` 线性混合，实现真实动态微痕复现。
3. **残字热点 (Hotspot Coordinates)**：
   - 热点锚定在碑石表面三维坐标 $(x_i, y_i, z_i = 0.185)$，随着模型旋转缩放始终精确锁定在对应字格上方，背面观察时根据法线夹角自动衰减隐藏。
