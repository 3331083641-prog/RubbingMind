# 时空图谱中心设计与实现约定

## Overview

本页使用用户提供的“曹全碑金石时空知识图谱”作为已指定视觉标准，继承现有应用导航及墨黑、泥金、朱砂、青瓷配色，只扩展图谱页面，不创建新的全站品牌系统。

目的：使研究者在碑刻、人物、史事和现代空间索引之间交叉考据；每一次选择都给出可追溯资料及定位精度。

参考图提供构图与材质方向，史实、馆藏号、人物及迁移关系以已核查资料为准。真实全国 GIS 和非地理实体网络分开呈现，通过共同 ID 联动；不以效果图中的装饰地貌代替真实空间。

## Colors

泥金用于标题、边框、选中控件、原石关联及时间轨道；青瓷用于地点、人物关联地及地理范围；朱砂强调网络核心碑刻；紫金用于纪年和文献。节点色与页面色是源码中实际存在的两套近似色，不强行归并为同一值。

深墨底色上的资料正文保持浅色，弱化文字只承担辅助说明。省界、真实水系和地形阴影与历史标记分层；光晕主要用于核心碑刻和选中地点。颜色值以上方 token 与源码为准。

## Typography

标题、模式及核心碑刻选择使用中文衬线栈，正文与输入控件继承现有应用字体。字体栈不等于这些字体都已下载；实际可用字体由浏览器回退机制决定。

页面标题采用响应字号；面板标题基准 17px，宽屏考据标题 19px，纪年面板标题 14px。实体名称 19px，小桌面降至 17px；页面正文 13px，证据说明 12px/1.75，控件与事件说明通常 10–13px。地图署名、坐标及页脚的 9–10px 是当前高密度研究页辅助层级，不作为其他页面正文标准。年度和坐标使用等宽数字。

## Layout

首屏沿用导航与全局碑刻状态；标题后设置四件核心样本。外层 `1.88fr : 1fr` 网格、右侧最小宽度 370px、间距 18px，接近参考图的65/35结构。1400px以下为 `1.8fr : 1fr`，右侧最小宽度345px、间距14px。下方为全宽动态时间轴；事件数量跟随史料，不以固定四项填充。

联动模式仅在左侧视区内地图与网络各占50%，不改变外层与侧栏比例。1050px以下外层单列，650px以下联动视区上下各占50%，资料与纪年依次排列。时间轴容许横向滚动。

地理：MapLibre负责投影、全国视角、南海同源附图、缩放、平移与地点按钮。省界、水系、地形来自独立真实数据，只有时间轴使用概念山水装饰。全国视图展示现代空间，不冠以未经验证的朝代疆域。

全国范围为 `[73,17]` 至 `[135,54]`，同源南海附图为 `[105,3]` 至 `[125,24]`。仅文字地点可关联区域索引；区域点默认缩放5.3，普通地点默认6，双击可请求11；多地点自动范围限制至8.2。放大不改变精度标记，也不把地区级点升级为考古精确点。

## Elevation & Depth

面板以深色层次、细金边和克制内阴影建立深度。真实栅格地形提供山川阴影，地形高光为低饱和青绿；山水建筑概念图仅用于时间轴背景和缩略裁切，不标为建筑复原或真实文物照。时间轴事件卡加深背景，保持文字可读。流光使用transform缩放，地图移动采用引擎动画；保留减少CSS动效的系统偏好，不将持续粒子效果纳入规则。

## Shapes

研究面板使用圆角细边，控件为较小圆角，碑刻选择有明确按下状态。网络实体采用内联SVG类别图形区分碑、人物、地点、纪年、文献，核心碑刻尺寸大于其他实体。地图标记采用小型类别字签，颜色、标签与选中环补充语义；字签只记录当前实现，不推广为全站图标规范。

## Components

网络：ECharts力导向布局；人物节点泥金、地点青绿、纪年文献紫金、核心碑刻朱砂；网络坐标不冒充地理坐标。节点与地理点通过共同ID关联。

筛选保留核心碑刻；节点与关系计数按筛后实际集合计算，关系必须两端可见才计入。小视区隐藏常驻关系文字，保留高亮查看。网络节点可拖动、缩放；地图有公制比例尺、实时中心坐标、图层开关及定位精度说明。

交互：四碑切换修改App既有选中ID；搜索、地图点击、网络点击、时间轴选择和播放均更新同一实体详情；人物关联及原石起讫使用不同虚线。未核实样本无虚构地点或人物。

五个模式入口为全国、碑刻地理、人物关系、历史轨迹与联动。纯网络模式点击“返回全国视图”先切回地图再执行全国命令。重置恢复视角、过滤、图层、时间范围、播放速度与初始纪年。考据侧栏五标签显示当前实体、地点或事件；地点显示WGS84坐标、精度、坐标方法、现代地名及来源。原石保存与数字拓本独立展示。

时间轴人物活动为青绿点，原石事件为金点；可点击、播放、暂停、重播和调整速度，末项停止。泥金虚线表示原石两端关联，青绿点线表示人物关联地，均不表示已证实行进路线。每碑初始纪年来自独立数据，未知输入不回退；年度干支不推算具体朔闰和公历月日。

性能：地图对象随数据变更更新源和标记，组件卸载时销毁；ECharts监听一次、ResizeObserver清理；地图及网络懒加载；本地数据分碑缓存。时间轴进度用transform，不用布局宽度动画。保留prefers-reduced-motion。

## Do's and Don'ts

- 保留参考图左右主次、泥金边框、考据标签与全宽山水时间轴；GIS来自真实数据与投影。
- 未知经纬度保留null，区域索引必须说明精度；不设置默认西安、不用随机偏移造点。
- 原石与数字拓本、概念装饰与真实拓图分开标注，不把两点关系认作迁徙路线。
- 上游声明的审图号不是本应用审图证明。行政区划镜像MIT声明、水系公有领域与地形署名已显示，完整许可链及公开审图仍未完成。
- 第四测试样本与《王诵墓志》同一性未确认，不补造人物与地点，不掩盖元怀图像和地望待核状态。

检查范围：1920×1080、1440×900、1366×768及补充390宽网页捕获。具体截图和browser-results.json位于screenshots/graph-final。公开地图审图、第四件样本文物同一性及元怀真拓来源尚无完整证据；设计不能掩盖这些限制。
