# 三维地貌重构 · 实施报告

> 本文只写**实测到的事实**。未能验证的项目在“未解决 / 限制”一节明确列出，不作“全部完美”的表述。
>
> 环境：Windows / Node v24.15.0 / Python 3.12.4 / Microsoft Edge（Playwright）/ ANGLE D3D11 / NVIDIA RTX 4060 Laptop GPU / WebGL 2.0

---

## 1. 结论摘要

- “时空图谱中心”的地图已由 **MapLibre 栅格山体阴影**升级为 **真实 DEM 驱动的 Three.js 三维网格地形**，通过 `CustomLayerInterface` 与地图投影/相机保持同一坐标系。
- 全国视图下中国占地图宽度 **69.9%（1920）/ 70.5%（1440）/ 70.4%（1366）**，落在要求的 65%–80% 区间。
- 运行时高程直接来自 DEM：珠峰 **6835 m**、拉萨 **3687 m**、塔里木 **1059 m**、四川盆地 **352 m**、华北平原 **71 m**、黄海 **0 m（海面）**。
- 全国网格 **620,964 顶点 / 1,238,770 三角面**，构建 **81–196 ms**；交互实测 **161.6 FPS**（1920×1080，1.48 s 内 240 帧，含拖拽与缩放）；从进入图谱页到三维地形就绪 **2.69 s**。
- 既有功能未退化：Python 测试 **122 passed**；原 `test_graph_browser.py` **全绿**（26 项检查、3 视口 × 4 碑、`browserErrors: []`）。

## 2. 核心实现

### 2.1 渲染架构

```
MapLibre GL 6.14  ── 相机 / 投影 / 交互 / 控制 ──┐
        │                                        │
        ├── 2D 样式图层（无 WebGL 时的回退）      │
        └── CustomLayerInterface "terrain-3d" ───┤
                     │                          │
              Three.js 0.163 ───────────────────┘
                     │
        ┌────────────┼──────────────┬───────────────┐
     地形网格      贴地矢量        DOM 标记       统计 HUD
```

- Three.js 直接复用 MapLibre 的 WebGL 上下文（`new THREE.WebGLRenderer({ canvas, context: gl })`），**不新建 canvas**，页面仍只有主图 + 南海附图两个 canvas。
- 关键矩阵：MapLibre v6 的 `render(gl, options)` 传入 `options.modelViewProjectionMatrix`，它映射**世界像素空间**；乘以 `worldSize = 512 × 2^zoom` 后即映射**归一化墨卡托空间**。该换算用 `map.project()` 逐点数值验证，误差 < 1e-12 px（含 42° 俯仰）。

### 2.2 高程与网格

- 每个顶点携带：位置（相对固定原点 `105°E,34°N` 的墨卡托坐标）、`aElev`（原始米）、`aGrad`（对墨卡托的梯度）、`aCurv`（离散拉普拉斯）、`aEdge`（边缘淡出）。
- 高度在**顶点着色器**中按 `z = elev × heightScale` 计算，`heightScale = 垂直夸张 / 2πR`。因此调整夸张不需要重建几何。
- 法线由梯度在片元着色器中逐像素求得：`n = normalize(-∂z/∂x, -∂z/∂y, 1)`，与绘制表面严格一致。
- 梯度取自 **5×5 二项式平滑后的高程**（仅用于着色导数），消除 DEM 纹理级噪点造成的砂砾感；网格顶点高度与 `aElev` 保持原始值。

### 2.3 LOD 与流式加载

| 层级 | 缩放 | 范围 | 预算 | 实际 DEM |
| --- | --- | --- | --- | --- |
| 全国地貌 | < 5.4 | 58°E–152°E, 2°S–62°N | 620k | z5 |
| 区域地貌 | 5.4–7.6 | 相机 ±11° | 460k | z6 |
| 局地地貌 | 7.6–10 | ±4.2° | 360k | z6（z8 缺失时降级） |
| 近景地貌 | ≥ 10 | ±1.5° | 300k | z6（z10 缺失时降级） |

- 全国网格常驻；细节片叠加并用 `polygonOffset` 在重合处胜出，无 z-fighting。
- `moveend` 后 160–220 ms 防抖重建；重建期间旧网格继续渲染，不出现空洞。
- 只请求**目标层级**瓦片；404 时向父级回退。首屏不会拉取整棵金字塔（早期实现曾一次性下载全部层级，已修复）。
- 瓦片在 Web Worker 中用 `OffscreenCanvas` 解码为 Float32，主线程只做双线性采样。

### 2.4 材质

- 15 段 sRGB 色带烘焙为 256×1 LUT：深墨海面 → 青黛低地 → 岩石灰 → 泥金高地 → 浅色雪线。
- 方向光（西北偏上）+ 半球环境光（天空/地面双色）+ 山脊轮廓光；坡度陡处混入岩石灰；凹地由 DEM 拉普拉斯压暗。
- 等高线每 800 m 一条，`fwidth` 控宽；当线密度超过像素可分辨范围（全国视图高原）时自动淡出，避免摩尔纹。
- 空气透视（按相机距离）与包围盒边缘 14% 淡出，使地貌融入墨色纸面。

> 调试记录：首版把 `THREE.Color` 生成的线性色值当作 sRGB 再解码一次，导致整体过暗；改为直接解析十六进制 sRGB 字节后色彩才正确。这类缺陷只有看真实截图才能发现。

### 2.5 矢量贴地

- 省界、国界、水系、定位面、关联线逐点采样**同一 DEM**，抬高 40–120 m，使用屏幕空间扩展 ribbon 绘制（线宽以 CSS 像素恒定）。
- 省界 0.58 透明度泥金、国界 0.95 泥金加粗、水系青绿；虚线用于定位面与关联线（并保持“非行进路线”的语义说明）。
- 地点标记改为自建 overlay：每帧用同一 `mvp` 把 `(经度, 纬度, 地形高度)` 投到屏幕，**标记贴在真实地表**而非海平面。DOM 类名（`.historical-marker`、`.marker-label`、`.province-label`）与既有 CSS/测试保持一致。

### 2.6 构图与交互

- 全国取景不使用 `fitBounds`（它假设俯仰为 0），而是对缩放做二分，使投影后的中国外框落入留白，再用 `panBy` 把投影重心对到视口中心。窗口尺寸变化时自动重新校准。
- 交互：滚轮缩放、拖拽平移、方位旋转（±30° 按钮 + 指南针）、倾斜、一键俯视（俯仰 0）、一键全国构图、二维/三维切换、边界/水系/等高线/关联线开关、垂直夸张（自动 / ×1 / ×8 / ×16 / ×24 / ×32）、地点检索与双击放大、图谱联动。
- 二维模式复用同一引擎：`u_heightFactor = 0` 去掉垂直位移但保留 DEM 晕渲，得到与三维同色的平面晕渲图；MapLibre 样式图层保留为无 WebGL 时的回退。

## 3. 数据来源与分辨率

| 项目 | 实际使用 |
| --- | --- |
| DEM | AWS Open Data Terrain Tiles（Mapzen terrarium），无需密钥 |
| 层级与分辨率 | z5 ≈ 4.4 km/px（全国）、z6 ≈ 2.2 km/px（区域）；z0–z3 全球 |
| 入库体量 | 334 块 PNG、26.8 MB；`manifest.json` 记录真实层级范围，`provenance.json` 记录逐块下载与校验 |
| 高程基准 | 上游 EGM96 大地水准面（SRTM/GMTED/3DEP 混合），**不是** WGS84 椭球高 |
| 中国版图 | 天地图行政区划镜像（CGCS2000，上游声明 GS(2024)0650），**本应用未单独审图** |
| 水系 | Natural Earth（公有领域） |

完整清单、实测高程表、未取得数据与授权说明见 [DATA_SOURCES.md](DATA_SOURCES.md)。

- **近景（≥ z10）**：仓库只带 z0–z6，近景层级会自动降级到 z6，画面变平滑（不伪造）。

## 6. 未解决 / 限制（如实记录）

1. **未单独审图**：中国版图沿用天地图镜像，页面出处栏已声明“上游审图号不是本应用审图证明”。
2. **Copernicus DEM / USGS / NASA Earthdata 未取得**：需要账号与配额，本次未注册；使用无需密钥的 AWS Terrain Tiles。
3. **高分辨率数据未入库**：z7–z9 需运行 `scripts/fetch_terrain_dem.py`；未运行时区域/近景层级平滑降级。
4. **南海诸岛附图仍为二维实例**：作为小尺寸定位附图保留，不参与三维渲染。
5. **标记不参与遮挡**：DOM 标记始终绘制在地形之上，山体不会遮住标记（MapLibre 原生标记同样如此）。
6. **低端设备未实测**：仅在 RTX 4060 笔记本上测得帧率。
7. **二维模式的实现变更**：现与三维共用引擎（平面晕渲），`chinaMapStyle` 的栅格浮雕仅作回退；如果后续希望二维恢复独立样式，需要重新启用对应图层。
