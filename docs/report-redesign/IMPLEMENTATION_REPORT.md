# 实施与验收

## 实现

将旧版长结论、三联图和多个小图同时堆叠的结构改为单一分析舞台与证据导航。桌面主区约 72%，手机改为一列与横向可滚动的导航；当前批次、方法、所选指标和负差始终可见。首次显示真实配对 ΔPSNR 横向图，提供指标切换、方法及文物联动、零线与可靠置信区间。

真实图像、退化热图、状态分布、质量 / 耗时、失败案例、机制流程和完整记录均可进入舞台；本件运行报告维持独立入口。原有三联的同步缩放、滑杆、ROI 预览、差分及校验保留。失败墙选择案例后打开原始输入 / 输出；所有负差仍可在完整诊断表核查。机制步骤只读历史重放，记录缺失显示未记录，并保留历史 head 提示及完整 JSON / SHA 细节。

状态分布把配对正差、负差、零差、原图返回、未知 / E-05 和执行失败分开，正差不等于认证的成功。顶部负差计数包含所有非失败、有配对值的行，不把未知状态漏掉。热图按文物等权，范围仅限当前批次和同一口径。耗时图的质量与耗时来自**同一组有记录的配对行**，只在记录了实验环境时显示，不作跨环境比较。图表使用原实验行、DER 和已有统计适配层；空值不填零。

默认收起三口径细表、bootstrap、完整 SHA、史料来源、跨批对照及逐条诊断；这些仍可展开。JSON 附带相同绘图原值与筛选，PDF 增加热图数值和状态分布附表，既有完整科研说明和病例信息仍保留。发生浏览器打印或 JSON 下载启动错误时给出明确提示；浏览器不提供保存对话框是否被取消的结果。

主图、热图、状态条和散点使用 ECharts 渐进动画；标题、指标与导航轻量渐显，真实数值以固定精度平滑到最终值。共享视图过渡提供图窗到舞台的空间切换，缺少原生 API 时用 transform / opacity 的 FLIP 过渡；`prefers-reduced-motion` 和低并发设备关闭主要动画。专注模式不清空筛选，ESC 恢复；图表使用 ResizeObserver 并释放实例。打印使用稳定终态。

修复无效 / 跨文物运行链接被清除后可能自动选择另一条运行的问题，并阻止切换文物时导出旧运行。修复打印用离屏 ECharts 让页面多出空白的问题。实验加载、后端断开、缺失实验 / 图像 / 运行和打印启动失败均有状态提示。首页核心样本已核查为 `object-contain`；首页视频、模型、馆藏原图和 V2.2 地图未改动。
