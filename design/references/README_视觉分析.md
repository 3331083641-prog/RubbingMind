# 《墨韵智考》设计参考图视觉与结构深度分析报告

## 一、 项目视觉风格定位与色彩规范
本系统采用**宋式金石美学 × 博物馆级数字展陈 × 高端科技 SaaS**的设计语言：
- **主背景色**：`#0C1113`（深邃玄青墨黑），搭配极淡水墨山水与暗纹网格底衬。
- **面板深色**：`#151C20`，配 `1px solid rgba(212, 175, 55, 0.18)` 泥金微光边框，卡片采用半透明毛玻璃 (`backdrop-filter: blur(14px)`)。
- **泥金主色**：`#D4AF37` / `#F5D46E`，用于核心标题、激活态边框、关键数据指标、激光扫描线、雷达图主线。
- **朱砂红强调色**：`#C83C23` / `#EE5C42`，用于系统方印 Logo `[墨]`、漫漶残字发光块、主行动按钮（CTA）、知识图谱核心碑刻节点。
- **青瓷绿辅助色**：`#3E8E7E` / `#62C0AC`，用于异体字考释标注、+24.6% 正向增益徽章、知识图谱地理与寺院节点。
- **宣纸米黄色**：`#F3EBDC` / `#FAF6EE`，用于古籍乌丝栏阅读区、学术考据报告预览区。
