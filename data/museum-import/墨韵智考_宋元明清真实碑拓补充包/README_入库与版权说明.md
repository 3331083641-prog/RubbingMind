# 墨韵智考｜宋元明清真实碑拓增量资料（16件）

## 真实性与下载状态
- 本压缩包**不包含16张已经下载的实物拓片图片**，只有可核验来源的馆藏目录、来源页与下载脚本。
- 11件台北故宫馆藏已定位到 Wikimedia Commons PDF（PDF 中含故宫 IIIF 数字影像），可使用下载器。
- 1件元代和4件清代属于馆藏著录核实但原始数字图/许可尚待人工核查。**这些条目不能未经原始影像核验就作为成功入库的“高清真实拓片”。**
- 本资料的朝代分组指 **碑刻/题刻制作年代**，不是后世拓印的年代。
- 本资料 **不包含 AI 生成拓本**。
- 所有表中未给出原碑确切年份的条目必须标注“具体年份待考”；不可猜填。
- 不得把拟制历史纹理或合成风化图说成馆藏原拓。

## 给 Antigravity 的操作步骤
1. 将整个资料包解压至 D:\RubbingMind\assets\museum-research\song-yuan-ming-qing\，不覆盖现有业务文件。
2. 读取 `宋元明清_16件馆藏清单.json` 和 `墨韵智考_七时期28件合并清单.json`，按 `id` 去重。
3. 在本机 Python 环境执行 `python -m pip install requests pymupdf Pillow`。
4. 执行 `python 工具/download_verified_commons.py --dry-run` 预览计划。
5. 执行 `python 工具/download_verified_commons.py --album-pages 4` 下载11件已获授权标识的 Commons PDF 并提取图像。
6. 对 `source_kind=catalog_record` 的其余5件，打开馆藏来源页，人工检查图像实际可用性及再利用条款；未完成前仅保留“馆藏目录记录/待取图”状态。
7. 将真正成功下载的图片复制/软链到网页所用的 public/assets/rubbings/，保留原始文件、SHA256、拍摄馆藏来源及授权信息。
8. 主页与典藏馆元数据中增加原碑年代、拓本年代、收藏机构、馆藏号、图像来源和状态；不写死无法验证的PSNR/SSIM数据。

## 用户体验建议
- 历史朝代增加【宋代】【元代】【明代】【清代】四个筛选器；旧碑拓筛选器保持可用。
- 典藏卡片中增加【查看原始馆藏记录】超链接。
- 完成下载后可显示“真实馆藏拓本”；未下载的目录只显示来源与“待取图”，不许用 AI 图像代替。
- 卡片点击进入修复工作台时，实际载入该条目的数字图像，并允许与真实、单独标记的人工合成损伤版本对照。
